# 데이터 설계표: 나의 독서 노트

`docs/features.md`의 저장할 정보를 표 두 개로 나눴다. 책 한 권에 메모가 여러 개 붙는다.

## 책 (Book)

| 칸 | 이름 | 자료형 | 필수 | 설명 |
|---|---|---|---|---|
| 제목 | title | 글자(200자) | 예 | |
| 저자 | author | 글자(100자) | 아니요 | |
| 읽는 상태 | status | 선택지 | 예 | 읽고 싶음, 읽는 중, 다 읽음. 처음은 읽고 싶음 |
| 별점 | rating | 작은 숫자 | 아니요 | 1-5 |
| 다 읽은 날 | finished_on | 날짜 | 아니요 | 오늘보다 뒤일 수 없다 |
| 등록한 때 | created_at | 날짜와 시각 | 자동 | |

## 독서 메모 (Note)

| 칸 | 이름 | 자료형 | 필수 | 설명 |
|---|---|---|---|---|
| 책 | book | 책을 가리킴(외래 키) | 예 | 책을 지우면 메모도 함께 지운다 |
| 메모 | body | 긴 글 | 예 | |
| 쓴 때 | created_at | 날짜와 시각 | 자동 | |

## 나중에 더한 칸
- 7부: 책에 표지(cover, 이미지), 주인(owner, 사용자를 가리킴)
- 8부: 책에 AI 요약(summary), 태그(tags)와 각각 AI가 만들었는지 표시, AI 호출 기록 표(AICall)
