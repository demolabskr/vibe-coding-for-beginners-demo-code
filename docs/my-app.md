# 내 웹앱 설계: 업무 일지

`docs/my-idea.md`를 독서 노트와 같은 순서(기능 목록 → 데이터 설계 → 화면 → AI 기능)로 옮겼다. 코드는 `05-my-apps/work-log`에 있다.

## 기능 목록
- 처음 만들 기능: 오늘 한 일 적기(날짜, 내용), 지난주부터의 기록을 날짜순으로 보기, 로그인과 내 기록만 보기
- AI 기능: 이번 주나 지난주 기록으로 주간 보고 초안 만들기(이번 주 한 일, 진행 중인 일, 다음 주 할 일)

## 독서 노트에서 다시 쓰는 것
- 로그인(Django 기본 인증), 주인 칸으로 내 기록만 보기
- Codex 호출 함수(`ai.py`), 지시문과 입력을 나누는 `build_prompt`, `.env`와 `make_env.py`

## 데이터 설계

### 업무 기록 (Entry)

| 칸 | 이름 | 자료형 | 필수 | 설명 |
|---|---|---|---|---|
| 주인 | owner | 사용자를 가리킴 | 예 | |
| 날짜 | day | 날짜 | 예 | 처음 값은 오늘 |
| 한 일 | body | 긴 글 | 예 | |
| 적은 때 | created_at | 날짜와 시각 | 자동 | |

### 주간 보고 (WeeklyReport)

| 칸 | 이름 | 자료형 | 필수 | 설명 |
|---|---|---|---|---|
| 주인 | owner | 사용자를 가리킴 | 예 | |
| 주 시작일 | week_start | 날짜 | 예 | 그 주의 월요일. 주인과 함께 겹치지 않는다 |
| 보고 내용 | body | 긴 글 | 예 | |
| AI가 만든 초안 | by_ai | 참과 거짓 | 예 | |
