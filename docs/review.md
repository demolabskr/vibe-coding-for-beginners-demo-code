# 코드 검토 결과: 04-reading-note

9부에서 새 채팅의 Codex에게 검토를 맡겨 받은 의견과 반영 결정이다. 이 웹앱은 내 컴퓨터에서 나 혼자 쓴다는 조건으로 골랐다.

| 의견 | 기준 | 결정 |
| --- | --- | --- |
| 통계의 평균 별점은 올해 책으로 좁히지 않고 별점을 준 모든 책으로 계산하는데, 화면 이름만으로는 알 수 없다 | 이해하기 쉬움 | 고침: 이름을 '평균 별점(별점을 준 모든 책)'으로 |
| 책을 지우거나 표지를 바꿔도 `media/covers`의 옛 사진 파일이 남는다 | 동작 | 고침: 지울 때와 바꿀 때 옛 파일을 지운다 |
| `settings.py`에 `DEBUG = True`가 그대로 적혀 있어 디버그 모드가 늘 켜져 있다 | 보안 | 미룸: 보안 점검 때 .env로 옮긴다 |
| 로그인 실패 횟수에 제한이 없다 | 보안 | 넘김: 나 혼자 쓰는 웹앱 |
