# 기능 목록: 나의 독서 노트

`docs/idea.md`를 바탕으로 정리했다. 처음 만들 기능과 나중 기능을 나눈다.

## 저장할 정보
- 책: 제목(필수), 저자, 읽는 상태(읽고 싶음, 읽는 중, 다 읽음), 별점(1-5), 다 읽은 날, 표지
- 독서 메모: 어느 책의 메모인지, 내용, 쓴 때

## 처음 만들 기능 (터미널 프로그램)
1. 책 추가: 제목과 저자를 받는다. 상태는 '읽고 싶음'으로 시작한다.
2. 목록: 번호, 제목, 저자, 상태를 보여 준다.
3. 검색: 제목이나 저자에 들어 있는 말로 찾는다.
4. 상태 바꾸기: 번호를 고르고 새 상태를 고른다.

## 메뉴 흐름
메뉴 보여 주기 → 번호 고르기 → 기능 처리 → 메뉴로 돌아가기 (5번을 고르면 끝)

## 나중 기능 (웹앱에서)
- 별점과 다 읽은 날, 독서 메모, 표지 사진
- 수정과 삭제, 정렬과 페이지 나누기, 통계(올해 읽은 권수, 달별 권수, 평균 별점)
- 로그인과 내 기록만 보기
- AI 기능: 메모 세 줄 요약, 장르 태그 자동 분류, 다음 책 추천
